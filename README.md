# وقع كوره قضم (Whack-a-Mole)

لعبة بسيطة تعتمد على الضغط على الكرات (الكرات الحمراء) قبل ما تختفي في الثقوب.

## كيفية اللعب
1. اضغط على زر "ابدأ اللعبة".
2. ستظهر كرات حمراء في الثقوب العشوائية.
3. اضغط على الكرات قبل ما تختفي لزيادة نقاطك.
4. لديك 30 ثانية فقط!

## المتطلبات
- متصفح ويب حديث (Chrome, Firefox, Edge, Safari).

## كيفية التشغيل
1. افتح ملف `index.html` في المتصفح.
2. استمتع باللعب!

## مزايا اللعبة
- تصميم بسيط وجذاب.
- سهلة اللعب.
- عد تنازلي للوقت.
- عرض للنقاط.
